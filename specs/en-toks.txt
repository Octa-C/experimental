Token Specification:

KW
  Loops
    - for
    - do
    - until
    - continue
  FUNC
    - function
    - return
  CONDITIONAL
    - if
    - else
    - elseif
    - caseof
    - case
    - default
  Word-based Logic/Rel Ops
    - and
    - or
    - not
    - is
    - in
  MISC
    - break

DT
  - Scalar 
    | i64
    | i32
    | i16
    | f64
    | f32
    | f16
    | bool 
  - Vector
    | i64vec
    | i32vec
    | i16vec
    | f64vec
    | f32vec
    | f16vec
    | boolvec
  - Matrix
    | i64mat
    | i32mat
    | i16mat
    | f64mat
    | f32mat
    | f16mat
    | boolmat
  - string

  - {
  - }
  - (
  - )
  - [
  - ]
  - ;
  - ->
  - ,
  - ... (ellipses)
  - :
  
Operators
  Standard
    - +-
    - * / %
  Matrix
    - '
    - .*
    - ./
  Relational and Comparison Ops
    - < (less than)
    - > (greater than)
    - <=
    - >=
  - Assignment

constants
